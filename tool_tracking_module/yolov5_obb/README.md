# Real-time Multi-Instrument Motion Tracking Module

This repository provides a multi-task orientated instrument network for instrument detection and long-term instrument motion tracking in real-time.

## Highlights

- Rotated-object detection with a YOLOv5-OBB model.
- Long-term instrument motion tracking.
- Per-tool trajectory rendering and stabilized top-left-corner markers.
- Video and NumPy (`.npz`) outputs for downstream analysis.
- A small, reproducible demo video and checkpoint layout.

## Requirements

- Linux (validated on Ubuntu)
- Python 3.10
- Conda or Miniconda
- NVIDIA GPU and driver for GPU inference
- CUDA-enabled PyTorch compatible with the installed driver
- CUDA compiler only when rebuilding the rotated-NMS extension

CPU execution is useful for debugging, but GPU inference is recommended for
video processing.

## Installation

From the repository root:

```bash
conda create -n yolov5_obb_topleft python=3.10 -y
conda activate yolov5_obb_topleft
python -m pip install --upgrade pip

# Example only: choose the PyTorch CUDA build appropriate for your system.
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

pip install -r requirements.txt
pip install filterpy shapely lap
```

Use the command generated by the [official PyTorch installation
selector](https://pytorch.org/get-started/locally/) if CUDA 12.8 is not right
for your system. Do not install a CPU-only PyTorch build when GPU inference is
needed.

### Build the rotated-NMS extension

The detector imports a local C++/CUDA extension named `nms_rotated_ext`.
Build it once after activating the environment:

```bash
export CUDA_HOME="$CONDA_PREFIX"  # or the path to a compatible CUDA toolkit
export CC=/usr/bin/gcc
export CXX=/usr/bin/g++

# RTX 5090 (Blackwell) only. Set the architecture appropriate for your GPU.
export TORCH_CUDA_ARCH_LIST=12.0

pushd utils/nms_rotated
python setup.py build_ext --inplace
popd
```

Check the environment and extension:

```bash
python -c "import torch; from utils.nms_rotated import nms_rotated_ext; print(torch.__version__); print(torch.cuda.get_device_name(0))"
```

## Quick start

The included demo video is `assets/test001.avi`. The matching checkpoint is
`runs/train/exp1/weights/best.pt`; it detects the three tracked medium-tool
classes (`1`, `3`, and `5`).

```bash
conda activate yolov5_obb_topleft
export LD_LIBRARY_PATH="$CONDA_PREFIX/lib:$LD_LIBRARY_PATH"
export MPLBACKEND=Agg  # avoids a Matplotlib GUI requirement on headless machines

python match/yolo_track_multi_pure.py \
  --weights runs/train/exp1/weights/best.pt \
  --source assets/test001.avi \
  --img 640 \
  --device 0 \
  --classes 1 3 5 \
  --conf-thres 0.1 \
  --project match/runs/detect \
  --name demo_test001 \
  --exist-ok
```

Add `--view-img` to display frames in real time. This requires a graphical
desktop session; it will not open a window in a headless SSH session without
X11/Wayland forwarding.

To use a custom video, replace `--source` and provide a checkpoint trained
with compatible class and corner-label definitions.

## Outputs

For the command above, results are written to:

```text
match/runs/detect/demo_test001/
```

| File | Description |
| --- | --- |
| `test001.avi` | Annotated video containing final tracked OBBs, trajectories, and stabilized corner markers. |
| `test001.npz` | Per-frame tracked and raw top-left-label arrays. |

The NPZ archive contains these arrays:

```text
count
topleft1, topleft2, topleft3
raw_topleft1, raw_topleft2, raw_topleft3
```

`topleft*` contains the stabilized tracker label; `raw_topleft*` contains the
unfiltered detector label for the corresponding frame.

## Top-left corner labels

Corner labels identify one of the four polygon vertices. A valid stabilized
label is displayed as a coloured circle on the corresponding OBB corner.

To reduce flicker, the category tracker waits for approximately 17 consecutive
consistent observations before publishing a corner label. Until then, no
corner marker is drawn. The output video shows a marker, rather than printing
the numeric labels `1`–`4` beside the tool.

## Troubleshooting

- **`ModuleNotFoundError: models`**: run the command from this repository root
  and use `match/yolo_track_multi_pure.py`; the script adds the repository root
  to Python's module search path.
- **`ModuleNotFoundError: nms_rotated_ext`**: build the extension from
  `utils/nms_rotated` as described above.
- **`Weights only load failed`**: use the current repository version. It loads
  trusted legacy YOLO checkpoints with PyTorch's compatible
  `weights_only=False` setting.
- **`module 'numpy' has no attribute 'int'`**: use the current repository
  version, which replaces the removed alias in the active tracker.
- **CUDA architecture error**: rebuild the NMS extension with a
  `TORCH_CUDA_ARCH_LIST` value matching the GPU.
- **No real-time display**: add `--view-img` and run from a graphical session;
  the annotated video is saved even when no display is available.
